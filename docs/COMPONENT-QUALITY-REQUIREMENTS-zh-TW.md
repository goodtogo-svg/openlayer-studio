# 部件提取與母版重建：最低品質要求

生效日期：2026-11-07。適用所有後續部件提取、遮罩、去特效、遮擋補全、素材母版及 Adobe 重建交付。這是交付門檻，並非聲明目前所有引擎或既有產物均已達成。

## 設定品質基準

每個工作室或專案應指定一張自己有權使用的參考圖，作為部件最低視覺品質的基準。參考圖不隨本專案發布；請放在專案外或 `quality-reference/`（已列入 .gitignore），並以 JSON 記錄：

```json
{"reference_id":"studio-quality-001","path":"quality-reference/reference.png","sha256":"<檔案 SHA256>","role":"minimum visual quality benchmark; not source geometry ground truth"}
```

參考圖是結構、材質及透明素材可用度的門檻，不是原稿幾何的真值，也不代表已分離出物理上完全無光照的材質。

每種部件都須達到同等可用程度，保留原稿本身的風格；平面插圖、標誌不能為了滿足此建築案例的立體感而被擅自3D化。

## 必須同時滿足的要求

| 編號 | 項目 | 合格要求與檢查方式 |
|---|---|---|
| CQ-01 | 實體完整 | 取消所有外加效果及環境遮擋後，完整主體仍成立。階梯踏面、立面、側牆、基座連續；建築不得成為懸空薄片或拼接面片。其他部件依其結構檢查連接與厚度。 |
| CQ-02 | 幾何與原稿忠實度 | 透視、比例、姿態、朝向與重要輪廓符合原稿或明確的使用者修改。登錄門洞、門檻、階梯落地點、人物腳底等對應錨點；不能只對齊整張外接矩形。更換母版後重新登錄，不直接套舊座標。 |
| CQ-03 | 遮擋後完整度 | 隱藏前景物件後，後方主體不得留下前景形狀的洞、缺角或殘影。補全部分獨立記錄為推估，不宣稱為被遮住的原稿真實資料。 |
| CQ-04 | 空洞與遮罩正確 | 去除意外裂縫、漏底、斷階、硬裁切和背景殘留；門洞、鑰匙孔等真實空間必須保留。不能用「所有洞都填滿」當成品質指標。 |
| CQ-05 | 材質與細節 | 保留足夠的材質細節、自然明暗、倒角、內緣、厚度及反射。不得把有體積的素材壓成平色多邊形，也不得以過度拉伸的紋理冒充原材質。細節尺度須與原稿及最終輸出尺寸一致。 |
| CQ-06 | 透明素材可用 | 在灰、白、深色底檢視 Alpha 合成結果，確認沒有可見污染色、毛邊、白／黑邊或漏底；至少檢視100%及400%局部，再回到最終使用尺寸確認。透明區未顯示的RGB不等於可見背景污染，不能只看RGB預覽判定去背失敗。 |
| CQ-07 | 母版與外觀分離 | 保留材質本身必要的自然明暗與反射；外加發光、魔法光帶、粒子、氣氛調色、投影及雲霧遮擋獨立儲存。提供顏色、亮度、尺寸、模糊、混合模式、位置、遮罩等適用參數。直接在Adobe可編輯與需JSON重製的項目必須明確區分。 |
| CQ-08 | 畫面邏輯 | 重新合成後人物須落地、階梯接門檻、投光與陰影方向一致，光效受正確部件和遮罩約束。不要讓效果懸空、穿過門框、遮住應在前方的物件，或把接觸陰影疊在實體上方。 |
| CQ-09 | 原生可用與資料不變 | 在對應Adobe實際儲存並重新開啟；檢查素材、位置、層序、遮罩、原生調整層及fx可用。關閉效果後能回到母版。保留來源與參數版本、來源雜湊，原檔不得覆寫。 |

## 一票不合格情況

- 結構斷裂、意外透明洞、穿幫接縫、明顯錯誤透視、未接合的階梯或部件。
- 用光暈、粒子、濾鏡、雲霧、前景物件或原圖參考層掩蓋實體瑕疵。
- 材質被壓平、紋理尺度明顯不合理、邊緣有可見背景污染。
- 人物姿態或母版造型已被生成模型改變，卻只靠平移／拉伸就聲稱還原原稿。
- 只有自動測試、Alpha一致或原生檔能開啟，沒有實體與合成畫面的視覺證據。

## 驗收及狀態紀錄

每個部件都要記錄 CQ-01..CQ-09 的 `pass`、`fail` 或 `not_assessed`，附證據與審查者類型；不適用的細項須說明替代判準，不可直接略過整個品質項目。任何 `fail` 或 `not_assessed` 都不得宣告該部件品質完成；先作候選／待修交付，修正後再驗收。不用平均分數沖淡明顯瑕疵。

至少保存：來源與母版SHA256、部件獨立圖、三種底色比較、100%／400%局部、前景隱藏圖、效果開關圖、原稿與新構圖比較、幾何／光效／遮罩參數及Adobe重開證據。所有工作輸出放入 `jobs/` 與 `reports/`。

審查記錄區分 `agent_visual_review` 與 `user_approved`；代理完成檢查不能自動填寫使用者核准。這不新增逐步等待確認的流程，可持續在已授權範圍工作；未獲使用者回覆時如實保留核准狀態。

參考 [審查模板](component-quality-review-template.json)。模板及本文件本身不構成自動視覺評分器，也不會替既有不合格素材背書。

## 防止自我證明

輸出Alpha與輸入遮罩一致，只證明傳輸／儲存一致；若輸入遮罩有錯，不能反過來證明幾何完整。必須另對來源、使用者品質參考及完整實體進行視覺檢查。程式測試、幾何／材質審查、合成畫面審查及Adobe原生驗證是不同關卡，不能互相代替。

後續優先順序固定為：**先確認實體與材質品質，再登錄位置與遮罩，最後校準光效並驗證原生輸出**。既有工作稿不得因本要求新增而自動標成合格。
