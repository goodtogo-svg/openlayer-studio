# 場景重建（scene rebuild）：已驗收流程的紀錄與通用化

本文件記錄 2026-11-08 兩張膠帶海報（黃色 Yellow Tapes、藍色 Blue Tapes）經使用者驗收通過時的實作流程與參數，以及它們如何改寫成 `ali vector-rebuild --method scene` 的通用版本。6.png 科技橫幅的驗收參數另見 cloud-native v4 紀錄。

## 1. 已驗收版本到底做了什麼

驗收通過的不是「像素分割後描邊」，而是**把海報當成少數幾個設計物件重新排版**：

| 物件 | 驗收版做法 | 參數（驗收值） |
|---|---|---|
| 背景 | Illustrator 原生兩色漸層，徑向 | 黃：(43,43,42)→(8,8,8)，原點 (576, 1030)，長度 1060。藍：(49,49,48)→(7,7,7)，原點 (365, 630)，長度 700 |
| 主標 | 一行一個即時文字框。字設 100pt，`createOutline` 量墨水框，再**非等比縮放**讓墨水框對齊原圖墨水框，左上角對齊 | 黃：Impact，顏色 (243,241,240)。藍：Arial-BoldMT，(238,237,232)；導言兩行 Impact |
| 膠帶 | 矩形 + 框內即時文字，整組繞中心旋轉 | 黃膠帶 (250,218,18)，字 (21,40,32)；文字框為膠帶寬 80%、高 54% |
| 緞帶 | 旋轉色帶：橫跨寬度的線性漸層、兩端變暗、重複的即時文字 | 漸層 (17,41,118)→(44,142,253)→(24,47,133) 於 0/45/100；兩端暗化 52/8/0/8/52%；重複字間距約 188–190，透明度 max(40, 100−14·|n|) |
| 層序 | 主標與膠帶交錯，逐一指定 | 例：黃 LEVELS→DESIGN IN TYPE→CROSS→LETTER PLAY→FONT POWER→TAPES→CROSSING→YELLOW→WORDS TOOL |
| 陰影 | 以物件本身的透明度做高斯卷積，多個分量 alpha 聯集，存成獨立嵌入影像 | 黃膠帶 (dx,dy,半徑,不透明度)：(3,8,4,.30)(3,23,14,.40)(3,42,26,.18)；黃主標 (2,25,14,.43)(2,40,26,.16)；藍緞帶 (1,4,2,.42)(2,13,7,.48)(3,25,16,.23)；藍主標 (2,15,9,.42)(2,26,17,.17) |
| 材質 | 只用在藍緞帶：以原圖藍色像素對基底 [1,u,u²,v,v²,v³,uv,exp(−(v/.42)²)] 做穩健最小平方，加上固定種子的纖維雜訊與織紋 | 種子 1109，細雜訊 std 4.6，纖維增益 .32，擬合 RMSE 約 11.6–12.6 |
| 被擋住的字 | 由可見部分推回整個字 | FONT 的 T、CROSS、LEVELS、重複字完整拷貝 |
| 單位 | 1 px = 1 pt | |

結果：黃 12 圖層、10 個即時文字框、9 張嵌入陰影；藍 11 圖層、28 個文字框、16 張嵌入影像（陰影＋材質）。兩者都在 Illustrator 存檔、重開通過，並經使用者驗收。

當時的數字是人工對照原圖逐一量出來的，所以換一張圖就要重量。這正是「不應該是針對個案」要修的地方。

## 2. 通用版：哪些數字改成自動量測

`src/ali/vector_rebuild/scene.py` 把上表每一列變成量測步驟；`scene_build.py` 依同樣的建構規則輸出。

1. **背景**：在非物件像素上擬合 Illustrator 兩色漸層（徑向：原點、長度；線性：角度、起訖），取誤差最小者。
2. **文字行分類**：OCR 每行外圈畫一個細環（頁面座標，不受旋轉誤差影響）。環上主要顏色不是背景、且佔一半以上 → 這行字在「板」（膠帶、緞帶）上；否則是主標。字色取沿整行分布、對比最高的色群。
3. **膠帶／緞帶幾何**：從字行外圈取顏色調色盤，找出與它連通的同色區域（含亮面與陰影面、漸層），以最窄投影求角度，再取長寬。被主標遮成兩段的同一條帶（例如 FON｜POWER）依「共線、同高、同色相」合併。帶子跑出畫面時延伸到畫面外。
4. **填色**：帶內逐列取色，差異小於 25 → 單色；否則跨寬度 5 點漸層，並量測沿長度的兩端暗化。只有「中央亮、兩端暗」且向量漸層解釋不了的帶子才加材質影像（驗收版的藍緞帶材質法）；單色膠帶維持單色（驗收版的黃膠帶）。
5. **重複字**：同一條帶上出現同一字（含邊緣殘字 Vertica、ertical）至少三次 → 緞帶；由殘字位置推回完整字的中心，求間距與起點，透明度依各拷貝實測對比。
6. **層序**：兩物件重疊處，看帶子「字以外的列」是主標色還是帶色，決定誰在上；帶與帶之間比較各自的字是否可見。拓樸排序得到由下到上的順序。
7. **文字擬合（驗收規則）**：墨水框 → 非等比縮放；另外搜尋字距。只用「沒有被上層物件蓋住」的像素評分。
8. **補字**：被擋或誤讀的字，以字典候選（兩個編輯距離內、或 OCR 字串為其子序列，例如 LLS→LEVELS）逐一渲染，與可見墨水比對；明顯較佳才替換，並標記 `inferred`。OCR 漏掉的主標（被多條膠帶切斷的 LEVELS）用第二輪 OCR：只保留主標色，膠帶範圍內垂直補線。
9. **字型**：依序嘗試傳入的字型；同尺寸級別的主標共用一個字型（取總分最高者），避免同一組標題混用。
10. **陰影**：驗收值除以當時的物件高度，成為比例預設值，依新物件高度縮放（主標、膠帶、緞帶三組）。

## 3. 輸出

- `scene.json`：場景規格（可人工修改後重建）。
- `scene.svg`：具名群組、原生漸層、即時文字。
- `scene.pdf` / `scene.ai`：向量 PDF（PDF 相容 .ai），依層序逐物件繪製：陰影影像 → 板 → 材質 → 即時文字。
- `native/build-illustrator.jsx` 與陰影／材質 PNG：驗收版 Illustrator 腳本的移植，可在有 Illustrator 的機器上產生分層原生 .ai（每物件一圖層）。

`--method auto`（預設）先跑場景重建；成品與原圖的平均誤差超過 25 時，代表圖中有場景模型描述不了的圖形（圖示、徽章、照片），自動改用區域重建（`--method regions`）。

## 4. 找最相近的字型（`--font-pool`、`--font-names`）

原稿用的字型通常不知道，本機也不一定有。用 `--font-pool <資料夾>` 指定本機字型的副本後，場景重建會從裡面挑「最相近的字型」：

- 一行字的可見字母若能各自分開，就逐字母比對：每個字母切出來，和候選字型同一個字母比形狀（正規化後的重疊）與寬高比。整行只允許一個共同寬度倍率，而且要扣分。字距和字偶不列入，所以靠加字距或拉寬硬湊的字型不會勝出。
- 字母分不開時（被遮住或互相黏住），改看整行貼合度。整行貼合度本來就會扣字距與變形的分數。
- 同一組字只用一款字型：所有膠帶上的字一款，大標題依字級分組各用一款。
- 用 `--font-names` 指定目標軟體實際認得的字型名稱，例如 Illustrator `app.textFonts` 匯出的 JSON。軟體裡沒有的字型不列為候選，以免打開時被替換。
- 每個文字物件都會在 `scene.json` 的 `font_match` 記下選到的字型、得分與前三名備選。這是「已安裝字型中最接近的」，不代表辨識出原稿字型。

雲端產出的檔案由用戶下載到自己的電腦用 Illustrator 開啟，所以候選字型只能是用戶拿得到的字型：

- 首選免費授權字型（OFL / Apache，例如 Google Fonts）。用到的字型連同授權檔會複製到輸出的 `fonts/`，附 `fonts.json` 和安裝說明。PDF 相容 .ai 的即時文字仍需在用戶電腦上安裝字型，否則 Illustrator 會換字。
- 字母相似度低於 0.75 時，`font_match.close_enough` 會標為 false，表示免費字型都不夠像，需要另找 Adobe Fonts 字型（有 CC 的用戶開檔時會自動啟用）。
- 開發機上的商用字型（Impact、Arial 等）不能用在雲端產出，也不能隨檔散布。

字型庫只放在工作資料夾，不進版本庫。

### Adobe Fonts 字型（`--adobe-fonts`）

最接近的字型若只在 Adobe Fonts 上（例如 Square721 的同源設計 Eurostile Cond），用 JSON 指定「哪個免費字族換成哪款 Adobe Fonts 字型」：

```json
[{"postscript": "EurostileCon-Hea", "family": "Eurostile Cond", "style": "Heavy",
  "url": "https://fonts.adobe.com/fonts/eurostile-condensed", "replaces_family": "Saira Condensed"}]
```

- 雲端沒有 Adobe Fonts 的字形，所以排版仍用被取代的免費字型量尺寸（版面代用字型）。
- `scene.pdf` / `scene.ai` 只寫 Adobe 字型名稱，不夾帶任何字型檔；Illustrator 開檔時自動啟用（需 Creative Cloud）。
- 雲端預覽與評分改用 `work/layout-proxy.pdf`（代用字型版）。`fonts/fonts.json` 的 `adobe_fonts` 列出要啟用的字型與網址。
- 代用字型與 Adobe 字型的字寬不同，必須在 Illustrator 開檔確認；`native/build-illustrator.jsx` 可用真正的字型重新貼合。

## 5. 已知限制

- 完全被遮住的字母只能靠字典與詞頻推測（例如 FON? POWER 可能推成 FOND 而非 FONT），一律標記 `inferred`，需人工確認。
- OCR 漏掉的標點不會出現（例如 THIS MEANS 後的破折號）。
- 只給 `--font` 時，只在給定的字型中挑；要找最相近的字型，請加 `--font-pool`。Illustrator 以 PostScript 名稱對應字型。
- 字母分不開的行，字型只能靠整行貼合度判斷，區分力較弱。
- 陰影與材質是近似參數，不是原作真值。
- 字典使用 `wordfreq`（程式 Apache-2.0；詞頻資料含 CC BY-SA 4.0 來源），未安裝時略過補字。
